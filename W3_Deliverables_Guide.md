## 📱 PART 2: Responsive Screenshot Capture Guide
Capture the Dashboard page at three responsive breakpoints (Mobile, Tablet, Desktop) using Chrome Developer Tools.

### Step-by-Step Breakpoint Capture (Dashboard)
1. **Launch the Local App:** Start the development server and navigate to your dashboard: `http://localhost:5173/dashboard` (or the active localhost port).
2. **Open DevTools Panel:** Right-click anywhere on the page and select **Inspect** (or press `F12` / `Ctrl+Shift+I` on Windows).
3. **Enable Device Mode Toolbar:** Click the **Toggle Device Toolbar** icon in the top left of DevTools (or press `Ctrl+Shift+M` on Windows).
4. **Capture Mobile (375px):**
   * Change the Device dropdown option to **Responsive**.
   * Set width: `375` px and height: `812` px (or typical phone height).
   * Confirm the grid columns stack vertically (1 card per row) and that no horizontal scrollbar appears.
   * Click the **More options** menu (three dots in top right of DevTools Toolbar) and select **Capture full size screenshot**.
   * Rename the downloaded file to: `mobile_dashboard.png`.
5. **Capture Tablet (768px):**
   * Set width: `768` px and height: `1024` px.
   * Verify the stats grid adapts cleanly (stacks 2 columns or wraps nicely) and spacing is balanced.
   * Click three dots > select **Capture full size screenshot**.
   * Rename the downloaded file to: `tablet_dashboard.png`.
6. **Capture Desktop (1440px):**
   * Set width: `1440` px and height: `900` px.
   * Verify the dashboard wraps inside a maximum container width (`max-w-7xl`) and elements are aligned.
   * Click three dots > select **Capture full size screenshot**.
   * Rename the downloaded file to: `desktop_dashboard.png`.
